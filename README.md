# Veri Pusulası sürümleri

Veri Pusulası masaüstü uygulamasının kurulum dosyaları ve imzalı güncelleme bilgisi (latest.json).
Kaynak kod bu depoda değildir.

**İndirme:** [Sürümler](../../releases/latest) sayfasından Windows için `VeriPusulasi-Kurulum-<sürüm>.exe`,
Mac (Apple Silicon) için `VeriPusulasi-<sürüm>-mac-arm64.dmg` dosyasını indirin. Kurulu uygulamalar yeni sürümleri
kendiliğinden bulur.
